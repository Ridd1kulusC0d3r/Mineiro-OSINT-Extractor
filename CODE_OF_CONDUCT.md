# Code of Conduct

Mineiro is an investigation tool, so how we work together matters as much as the code.

## Our standard

Be respectful, assume good faith, and keep feedback specific and technical. Welcome people of every background and experience level.

Not acceptable:

- harassment, personal attacks, discriminatory language or doxxing;
- using the project to target private individuals, or asking for help to bypass authentication, CAPTCHAs, paywalls or access controls;
- publishing credentials, tokens, personal data or non-public information in issues, pull requests or examples.

Investigation examples in issues and docs should use **public, organisational or synthetic handles**, never a real private person.

## Scope

This applies to all project spaces (issues, pull requests, discussions, reviews) and to anyone representing the project in public.

## Enforcement

Maintainers may edit or remove contributions, and temporarily or permanently restrict participation, when conduct breaks this standard. To report a problem privately, use GitHub's private vulnerability reporting on this repository (Security tab) or contact the maintainer through their GitHub profile.
